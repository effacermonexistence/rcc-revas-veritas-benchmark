# Claim boundary — 0.3.0

This release contains executable native integrations, a new bounded external RCC
verifier/adoption implementation, the original RCC source bridge, and real VERITAS
Bind/authority calls. The measured native profile coverage is in
`NATIVE_COVERAGE.json`; raw test results and real-data runs are retained.

Do not conflate these claims:

* Native boundary interoperability is not completion of every task in that framework.
* A real CPU model computation is not a pretrained frontier-model leaderboard run.
* Loading official SWE-bench predictions is not building its Docker grading environment.
* Candidate-level Bind refusal is not a whole-task utility or attack-success score.
* The new external RCC output-contract policy is not full private production RCC.
* Source hashes prove byte equality, not authority, truth or independent attestation.
* Local Ed25519 test authority is not production authority or Human Approval.
* Actual native Bind core invocation is not the complete `/v1/decide` and encrypted
  production TrustLog pipeline.
* Native reward/error messages retain their domain semantics; an error is not
  automatically a correct governance refusal or a zero-effect observation.
* Durable operation reservation prevents local retries. It is not a distributed
  exactly-once transaction or an OS sandbox.

No code change weakens or overwrites the historical synthetic-only release or
its adverse results. The new source and policy have separate identities. An
external dataset can be synthetic; dataset authorship, data origin, exposure,
independent evaluation and deployment readiness are separate dimensions.

No evidence here claims that all existing/future benchmarks, providers, models,
modalities, tasks or adversarial distributions were executed. The common interfaces
accept additional integrations without a hardcoded dataset count; untested native
bindings require their own execution evidence. Do not silently replace missing
runtime facts with a success flag, fabricated approval or hidden scoring label.

ENGINEERING/native validation and EXTERNAL_CONFIRMATORY experiments remain distinct.
Preserve failed attempts, exact native version/policy/scorer identities, private-state
projection, cohort-wide scoring barrier and exposure history. Full effectful customer
systems additionally require their own authority, state, timeout and recovery design.
