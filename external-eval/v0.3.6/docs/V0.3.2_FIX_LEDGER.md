# v0.3.2 change ledger

The parent is the delivered v0.3.1, commit d927c15e5c4c688aea693406abccf3ef5f256c5a.
No earlier result or source pin is retroactively repaired.

## Closed implementation gaps

1. Added `NativeDecisionIntentFactory`: authenticated native decision response,
   native CDA verification, response/CDA semantics equality, persisted receipt
   verification, exact chosen candidate and genuine canonical promotion.
2. Added optional native TrustLog persistence and independent receipt verification
   to NativeBindExecutor. An effect receipt is preserved before a persistence check
   can fail. Enabling persistence without a verifier is rejected.
3. Added the executable full native chain with signed compiled policy, independent
   signed authority, actual Bind effect and encrypted ledger/replay verification.
   Valid, signature-tampered and revoked modes execute in new processes.
4. Replaced per-benchmark just-in-time freezes/shared process execution with a
   whole-catalogue barrier and separate process per benchmark. Preparation errors
   prevent partial execution; post-freeze changes never silently refreeze.
5. Added native SWE schema preflight, exact enrollment/prediction coverage,
   official scorer invocation and complete native-report accounting. An unsolved
   model output is distinct from missing/failed grading.
6. Fixed a real v5 SWE dataset mismatch: the old Princeton-nlp records lacked
   image. The official v5 record source resolved it without fabricated values.
7. Fixed inherited hardcoded runtime `framework_version=0.3.0`; runs now record
   the loaded package version and the structural record validator recognizes it.
8. Pinned the tested FastAPI/Uvicorn versions and the boto3/botocore intersection
   required by aiobotocore; no dependency constraint was disabled to claim success.

## Recorded failed attempts

- Initial native imports lacked optional runtime dependencies; complete install
  was then made from checked source/dependency archives.
- Native replay verification initially used replay-source ID instead of the
  original canonical decision ID. This adapter bug was corrected.
- A draft response/CDA comparison incorrectly treated a Pydantic projection as a
  dict. Tests exposed it; comparison now uses native `model_dump(mode='json')`.
- Official SWE run 35948021895 failed at actual schema construction (`image`).
  Corrected run 35948823942 completed real Docker grading with resolved=true.
- The first final-run manifest exposed the inherited stale version field.
  The corrected new execution is separate and retains the old records.
